# Design notes — the ratified design record

Status semantics (A8, status-guarded): **draft** is working material, agent-writable;
**ratified** and **superseded** are agent-immutable — amendments are agent-drafted and land
only by the owner's merge (the role-state Amendment A1 precedent: *the merge is the hand*).

> **Epistemic note (owner rule 2026-07-28).** A note records design intent at its
> ratification cut — the code and tests at HEAD are the living truth. Notes are
> jumping-off points for investigation: ground against real callers and real state before
> building on a note's claims (the ground-before-building rule), and expect built reality
> to have moved past any note's snapshot.
