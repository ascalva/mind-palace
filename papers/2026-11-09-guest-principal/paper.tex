\title{A Read-Only Guest Principal for a Personal Knowledge Store}
\author{Alberto Serrano-Calva}
\date{9 November 2026}

\begin{document}
\maketitle

\begin{abstract}
A personal knowledge store answers sentences of a typed query algebra under a grant: a set of
scopes, one per clock, and a sentence is admitted when every clause's required scope lies under
some granted plane. The store's local model holds a grant that reads the owner's notes. We add a
second principal for an agent outside that trust boundary: a read-only grant over the dialogue,
the repository's code and documents, curated papers and observed records, and never the notes or
the model readings derived from them. The grant's properties are a finite check, proved in Lean:
it names no stratum of the notes after downward closure, so every clause over them is refused, and
it admits no command and no hypothetical. Admission bounds which rows a sentence reads; it does not
bound what an admitted row says. The transcript stratum records the path of every file a
conversation wrote, a note's included. An adversarial battery of 71 sentences over a fixture store
found five that returned a note's path, through a causal edge's endpoint and through
\texttt{witness}. A first repair withheld every edge that ends under the vault's path, and a red
team found five other spellings of a note's path that passed it. For a grant without the notes,
the universe a sentence reads now shows a causal edge only when it ends at a commit or at a file
the repository tracks, and withholds every other edge whole; a refusal raised while a sentence
runs reaches the guest as one fixed sentence for its class. After the change no output of the
battery, with or without its trace, carries a canary token placed in a note's path, title and
body, and the guest's outputs over two stores that differ only in the notes are identical. The
same holds over a store that embeds nothing and ranks by one lexical index holding the notes'
units beside the code's, the case of an external coding agent reading the repository: the guest's
rankings read the statistics of the classes its grant reads.
\end{abstract}

\section{Introduction}

The store \citep{palace2026} keeps several strata: the \emph{mirror} (the owner's notes),
\emph{interpreted} relations and readings that models derive from the notes, the \emph{dialogue}
(chat turns, the transcripts of agent sessions and the documents written in them), the
\emph{reference} stratum (the repository's code and documents), \emph{curated} papers, and
\emph{observed} records. Every read is one sentence of a query algebra, compiled under the
reader's grant; a clause whose required scope no plane covers is refused before any store
opens. Until now two principals held grants: the local model (the Ambassador) and the owner's own
surfaces. Both read the notes.

An agent run by someone else, or on another machine, should be able to ask about the code, the
papers and the conversations without reading the notes. The request is least privilege
\citep{saltzer1975protection}: a principal holds the authority its task needs and no more. In a
capability system \citep{dennis1966semantics} that is a smaller capability, and here it is a
grant. The contributions are:
\begin{itemize}
  \item a grant \str{GUEST} and a role \str{guest} that resolves to it, with its properties proved
        in Lean (row SCO-9 of the store's laws ledger);
  \item an MCP surface \citep{mcp2025} for the role, with two tools, \texttt{query} and
        \texttt{overview}, and refusals that pass on no reason raised against the stores;
  \item a leak found by an adversarial battery, an overt reference from an admitted stratum to an
        excluded one, and its repair in the universe builder, an allow list that fails closed;
  \item a noninterference test: the guest cannot tell two stores apart that differ only in what
        its grant excludes, whether the store embeds its items or ranks them lexically.
\end{itemize}

\section{Background and related work}

\paragraph{Scopes and grants.}
A scope is a point $(\Sigma, E, T, A)$ of a product lattice: a downward-closed set of strata
$\Sigma$ in a refinement forest (\str{mirror\_authored} below \str{mirror},
\str{dialogue\_transcript} and \str{dialogue\_artifact} below \str{dialogue},
\str{reference\_repo} below \str{reference}), a set of edge fibers $E \subseteq \{F, D, C\}$
(citation, version, causal), a clock and window $T$, and an authority $A$ (read or propose, a
write bit, a world reach). The order is componentwise. A grant is a list of scopes, one per
clock, because windows on different clocks have no meet. A sentence's clauses each require a
scope; the sentence is admissible under a grant iff each requirement lies under some plane
(QSA-5).

\paragraph{Clearances.}
Rows carry provenance classes, and a read is made under a clearance, a set of classes; a read
under a clearance returns rows of those classes only (PLN-1), and a reader cannot distinguish
states that differ outside its clearance through the shared vector plane (PLN-2, BRG-5). These
are Goguen and Meseguer's noninterference \citep{goguen1982security} for one store, in the
lattice model of information flow \citep{denning1976lattice}; language-based treatments type the
same property \citep{volpano1996sound,sabelfeld2003language}.

\paragraph{The universe.}
A sentence is evaluated on its \emph{support}: the nodes of the strata its admitted clauses read,
the nearest units to its texts in the indexed strata, and the citation and causal neighbourhoods
of its anchors. Nothing outside the admitted strata is loaded as a node.

\section{Theory}

\begin{definition}[The guest's grant]
Let $\operatorname{cl}(S) = S \cup \{c \ne \str{exhaust} : \operatorname{parent}(c) \in S\}$. The
guest's grant is the list of two planes
\begin{align*}
  p_1 &= \bigl(\operatorname{cl}\{\str{dialogue}, \str{reference}, \str{curated},
          \str{observed}\},\ \{F, D\},\ (\text{projection events}, \top),\ \text{read}\bigr),\\
  p_2 &= \bigl(\operatorname{cl}\{\str{reference}, \str{dialogue}\},\ \{F, C\},\
          (\text{commits}, \top),\ \text{read}\bigr),
\end{align*}
where \emph{read} is the least authority: no propose, no write bit, no world reach. It is the
local model's first two planes over these strata, without the third plane, which reads the
notes' version chains.
\end{definition}

\begin{theorem}[SCO-9]\label{thm:guest}
Let $M = \{\str{mirror}, \str{mirror\_authored}, \str{interpreted}\}$.
\begin{enumerate}
  \item The grant is one the code accepts: no plane names the foundation, and none reaches the
        world (\lean{guest\_grantOk}).
  \item $\Sigma_{p} \cap M = \emptyset$ for both planes (\lean{guest\_reads\_no\_note}).
  \item Every scope $r$ with $\Sigma_r \cap M \ne \emptyset$ lies under no plane, so a clause that
        requires it is refused (\lean{guest\_refuses\_note}).
  \item No command is admitted (\lean{guest\_admits\_no\_command}).
  \item No sentence under \texttt{assume} is admitted (\lean{Sentence.guest\_no\_assume}).
\end{enumerate}
\end{theorem}

\begin{proof}[Proof sketch]
(1) and (2) are finite checks, closed by evaluation (\lean{decide}); for (2) the closure adds
\str{dialogue\_transcript}, \str{dialogue\_artifact} and \str{reference\_repo}, whose parents are
in the set, and nothing whose parent is \str{mirror}. (3) $r \sqsubseteq p$ requires
$\Sigma_r \subseteq \Sigma_p$, which (2) contradicts. (4) A command requires the write bit, and a
grant whose planes all lack it admits none (ING-1, \lean{readonly\_admits\_no\_command}). (5) A
clause under \texttt{assume} requires the overlay stratum, so an admitting grant names it on some
plane (QSA-5, \lean{admissible\_assume\_overlay}); neither plane does. Lean 4 checks each statement
\citep{demoura2021lean4,mathlib2020}; the store's comparator judges the five against their
statements in \texttt{formal/Spec}, and six independent kernels replay the library.
\end{proof}

The theorem bounds what a sentence may \emph{require}. What it may \emph{return} depends also on
the data in the admitted strata.

\begin{definition}[Views and noninterference]
For a grant $g$ and a store state $\sigma$, let $\operatorname{ans}_g(s, \sigma)$ be the answer to
sentence $s$: its hits, notes and plan, or its refusal. Two states are $g$-equivalent,
$\sigma \sim_g \sigma'$, when they hold the same rows in every stratum $g$ names, and the same
edges among nodes of those strata. The grant is noninterfering when
$\sigma \sim_g \sigma' \Rightarrow \operatorname{ans}_g(s, \sigma) = \operatorname{ans}_g(s,
\sigma')$ for every $s$.
\end{definition}

A causal edge $(t, v)$ joins a transcript turn $t$ to a file $v$ the turn's action wrote. When $v$
is a note, the edge is a fact of the transcript stratum that names a node of the mirror. In the
lattice model its label is the join $\ell(t) \sqcup \ell(v) = \str{dialogue\_transcript} \sqcup
\str{mirror}$, which the guest's clearance does not dominate. Two $g$-equivalent states may differ
in such edges, so an answer that shows them, or counts them, interferes.

\section{Concepts and intuition}

Admission is a check on requirements. A clause over the notes is refused, and the universe never
loads a note as a node. The leak was not a note: it was a \emph{reference} to a note held by a row
the guest may read. The causal store records, for every action of an agent session, the path it
produced. A session that edited a note recorded the note's path, and the path carries the note's
name. The store already named such an endpoint, when the sentence did not read the mirror, as a
node of the transcript stratum: honest for the local model, whose grant reads the mirror anyway,
and a leak for any grant that does not. \texttt{witness} of the edge returned the same path.

The repair keys on the grant rather than the sentence. A grant's strata are the union of its
planes'. When they hold no stratum of the mirror, the reader may not see a mirror node named, and
an edge it may not see is withheld whole: not named by a placeholder, not counted, its
content-addressed id withheld with it. A placeholder per edge or a count would be a function of the
excluded data. The answer still says that edges are withheld, in one sentence whose words do not
depend on whether any were.

Which edges the reader may see is decided by an allow list. The first repair was a deny rule: it
withheld an edge whose endpoint lay under the vault's path, compared as text. A red team found
five spellings of a note's path that passed it: the vault's directory in another letter case and
the path in another Unicode normal form, each the same file on a file system that folds them; a
relative path; a \texttt{file://} URI; and the bare file name that the event projector keeps for a
file written under a \texttt{docs/design-notes} folder. A deny rule has to know every spelling of
a vault path, and an allow list only what may be shown. The reader is shown a causal edge only
when it ends at a commit, named by its hex sha, or at a file git tracks in the checkout at HEAD;
the vault is asked first, with every component folded for case and normal form, for the path as
written, normalized and resolved. A file system knows a note by names that check does not fold,
a hard link or its path through another mount of the volume; such a name is judged as any path
is, and shown only when it is a file git tracks in a checkout of the repository. What cannot be
judged, because git cannot be asked or the endpoint cannot be read, is withheld. The cost falls
on endpoints the rule cannot tie to a tracked file: a path outside the repository, a relative
path (even one that names a tracked file), a tracked file's path in another letter case or under
another clone, and an untracked or deleted file are no longer named to this reader.

\section{Implementation}

\Cref{alg:hide} is the change to the universe builder. The grant's strata are computed once per
sentence by the surface; a grant that reads the mirror builds the same universe as before, by the
same call.

\begin{algorithm}
\caption{Withholding the mirror from a reader whose grant does not name it.}\label{alg:hide}
\begin{algorithmic}[1]
\Require a plan $P$, the reader's grant $g$, the stores
\State $\mathit{hide} \gets \operatorname{strata}(g) \cap \{\str{mirror}, \str{mirror\_authored}\} = \emptyset$
\Function{Named}{$v$} \Comment{a causal endpoint; once per endpoint, false on any failure}
  \If{$v$ is a commit} \Return $v$ is a hex sha \EndIf
  \If{$v$ is the vault or under it, folded for case and normal form} \Return false \EndIf
  \State $r \gets$ the repo path of $v$: a doc id's one file, or an absolute path under a checkout
  \State \Return $r$ exists $\wedge$ git tracks $r$ at HEAD
\EndFunction
\Function{Citable}{$v$}
  \State \Return $v$ is a plain repo-relative path $\wedge$ no checkout's $v$ is in the vault
\EndFunction
\If{not $\mathit{hide}$} build the note graph \Comment{the dialogue otherwise loads under its own clearance}
\EndIf
\State index the causal edges $(t, v)$ with $\neg\mathit{hide} \vee \Call{Named}{v}$ \Comment{whole edges, ids with them}
\State expand citation neighbours $v$ with $\neg\mathit{hide} \vee \Call{Citable}{v}$
\State $\operatorname{witness}(e) \gets \bot$ when $\mathit{hide}$ and $e$ is an edge $(t, v)$ with $\neg\Call{Named}{v}$ or an attestation
\State through a reference edge, $\operatorname{witness}$ chooses among the edges keyed to its commit those with $\neg\mathit{hide} \vee \Call{Named}{v}$
\If{$\mathit{hide}$ and $P$ walks $C$ or witnesses} add the fixed withholding note \EndIf
\end{algorithmic}
\end{algorithm}

The role \str{guest} resolves to the grant at the ingress and holds no spool, so a request is
refused when it is compiled and could not be spooled. The surface is the store's MCP server with
\texttt{--role guest}: it seals the core against network egress, as the local model's server
does, and serves \texttt{query} and \texttt{overview}. The overview counts catalog entries of the
classes the grant's strata hold and the curated chunks; the local model's totals of vector rows,
relation edges and versions each count the notes and are not shown. On a store that embeds
nothing it also says so, counts the lexical index's units of the same classes, and names each
repository it lands with the commit it landed and how far the repository has moved since; the
local model's count of every lexical unit counts the notes' too. The \texttt{status} tool is not
served, since it lists the owner's open tasks and running jobs.

A refusal reaches the guest with its class and a text chosen by where it was raised. The surface
compiles the sentence again, with the trace when the call asked for one, since the trace renders
the parse and a sentence can fail to compile with it alone; that reads the sentence and the grant
and no store. If the compiler refuses it, the guest reads the compiler's reason with every quoted
run replaced by its length: the reason holds the asker's words. If it compiles, the refusal was
raised in the run, against the stores, and the guest reads one fixed sentence for its class,
never the reason, which may quote what a store holds. A redaction that pairs quotes by position
does not hide such a quotation reliably: an apostrophe in the reason's own words pairs with the
opening quote of a quoted path and leaves the path in clear. A scope refusal of either kind adds
the strata the grant reads. The server writes its replies to a copy of standard output's file
descriptor and points the descriptor itself at standard error, and a tool runs with Python's
standard output pointed there too, so the protocol stream carries replies only, whatever a library
or a child process writes. The query log, which the owner reads on a terminal, writes a guest's
sentence into one ASCII line, its first 4{,}096 characters, at most 8{,}192 bytes of the line,
and a marker of its length, and prints it with every character that is not printable escaped.

\section{Evaluation}

\paragraph{The fixture.}
A store on real stores (the vector plane, the catalog, the version and relation stores, the
attestations, the causal store and the chat log) holds a note whose path, title and body carry a
canary token made at run time, landed by the store's own ingress; an interpreted relation from the
note to an authored dialogue turn; an authored and an observed dialogue turn; a transcript turn
whose causal edges point at the note and at a repository file; a paper; a code atom; and a
citation graph at one cut. The test is \texttt{tests/adversarial/test\_guest\_leaks.py}.

\paragraph{The battery.}
It has 71 sentences: every verb (\texttt{near} with and without \texttt{over}, \texttt{diffuse},
\texttt{reach} over $F$, $C$ and $D$ in both directions, \texttt{relate}, \texttt{trace},
\texttt{walk} with paths over $S$, $F$, $C$ and $D$, \texttt{witness} of the note's edge, of the
file's edge and of the note's landing, \texttt{read}), \texttt{assume}, the adjectives and
connectives (\texttt{within}, \texttt{over}, \texttt{as of}, \texttt{top}, \texttt{atleast},
\texttt{far}, \texttt{not}, \texttt{and}, \texttt{or}, \texttt{minus}, \texttt{then}) and four
requests. Twenty name the note by its path or title. Each is asked through the MCP surface with
and without the trace.

\paragraph{The spellings.}
The fixture stands under a directory whose name has two Unicode normal forms. To it the test adds
nine causal edges from the turn, each holding the canary: the note's path with the vault's
directory upper-cased, the path in its other normal form, two relative paths, a \texttt{file://}
URI, the file name the projector keeps for a vault file under \texttt{docs/design-notes}, such a
name that is a glob's pattern for a tracked finding, an untracked path in the checkout and a path
outside the repository; and four citations from a repository file to the note's path and three
other spellings of it. The guest is asked the battery, a \texttt{witness} of each new edge and a
\texttt{reach C} back from each new endpoint, with and without the trace, and the overview, before
the edges are added and after: 181 outputs. Unit tests hold the rule at the universe builder over
a scratch git repository, and others hold the refusal texts, the query log and the protocol
stream.

\paragraph{Results.}
After the repair no output carries the canary, as a path, a title, a text, a count or a refusal,
and every sentence that names the note is refused (\cref{tab:battery}). The admitted strata
answer: \texttt{near} over all four returns the dialogue turns, the code file and the paper;
\texttt{read} returns a dialogue turn, a transcript turn, the paper and the file; \texttt{reach C}
from the turn over \str{reference} returns the file and not the note. Over a second store whose
note, relation, landing and vault edge differ, all 142 guest outputs and the overview are equal,
byte for byte, once the names the asker typed are normalized. As a control, the local model asked
the same 71 sentences receives the canary in 31 answers, through \texttt{near},
\texttt{reach C}, \texttt{witness}, \texttt{relate} and \texttt{read} among others, so the battery
reaches the channels it is meant to close. With the nine edges and four citations added, the 181
outputs are those before, byte for byte, no output of the battery carries the canary, and
\texttt{witness} of each new edge answers nothing; the local model is shown all thirteen. A
store's error whose reason quotes a path holding an apostrophe, which the redaction leaves in
clear, reaches the guest as its class and that class's sentence, and the path is on neither the
stream nor standard error. The default server keeps the local model's tool table and
instructions, and the store's deterministic test tier passes (3{,}699 tests). The commands are in
the repository: \texttt{uv run pytest} over \texttt{tests/adversarial/test\_guest\_leaks.py},
\texttt{tests/adversarial/test\_guest\_lite.py} and
\texttt{tests/unit/test\_sentence\_universe\_withheld.py}, and \texttt{sh formal/check.sh}.

\paragraph{A store that embeds nothing.}
The guest is meant to serve an external coding agent, and the store's code instance embeds
nothing: every item lands with its lexical units and no vector, a repository's files as items of
the reference stratum, and \texttt{near} ranks by BM25 \citep{robertson2009bm25} over one index.
A store of that profile can hold a vault, whose notes' units then share the index with the
code's and the dialogue's, so a ranking whose unit count, mean length or document frequencies
were read over the whole index would be a function of the notes. They are read over the classes
a ranking asks for, and each lexical path of the universe asks for classes the grant reads. A
second fixture embeds nothing: the note lands through the ingress, a scratch repository's three
files through its repository source, and the dialogue turns and the paper with lexical units
alone. Asked the 71 sentences and eleven of the code source's own (a lexical \texttt{near} over
the reference stratum, \texttt{read} of a landed file, \texttt{trace}, a file the repository does
not have), with and without the trace, the guest's 164 outputs carry no canary. Over a second
such store whose note's body says none of the queried words, in four terms where the first's
runs to over three hundred, and which is alike in all else the guest reads, its repository's
landing dated to the same second, they and the overview are identical, while the local model
ranks the first note first and counts more units in the first store. Three mutations checked by
hand each fail the test: a unit count and mean length read over every class, a reference seed
that searches every class, and an overview that counts every unit. The launcher, spawned over an
overlay made from the code instance's, answers \texttt{overview}, a lexical \texttt{near}, a
\texttt{read} and three refusals in their fixed words, one reply per request on standard output.

\section{Limitations}\label{sec:limits}

The grant bounds strata, not what admitted text says. A chat turn, a capture or an assistant reply
that quoted a note is a dialogue row, and the guest reads it; keeping such quotations out needs a
narrower grant (reference and curated alone) or a filtered dialogue. The withholding is code,
held by tests, not by a theorem: the Lean model states what a grant admits, not what the universe
builder returns. The isolation is in the process: the guest's server opens the stores under the
account it runs as, and an untrusted party should also be separated by the operating system.
Response times may depend on the size of the excluded strata; a lexical ranking, for one, reads a
term's postings in every class before it keeps its own. So may a time the guest reads: the
overview shows when each repository landed, and a landing of the notes queued before it in the
daemon's one queue delays it. The query log grows by a line for every sentence a guest asks, at
most some 12~KB each, and nothing bounds its size; nor is a sentence's size capped, though a
string literal is read in memory in proportion to its text. Both bounds are left to the owner.
The reference stratum holds what a store lands in it: a repository source is read through git at
its ref, and a repository whose tree tracked a vault's files would land the notes as code, which
the guest reads. The configuration does not refuse such a repository; the code instance declares
only the store's own.

Three limits follow from the allow list and the process. First, the event projector records a
file written under a \texttt{docs/design-notes}, \texttt{docs/findings} or
\texttt{docs/build-plans} folder by a bare doc id, with no path, wherever the folder is. A vault
file there is shown only when its id resolves to exactly one tracked document of the repository,
and then as that document: the guest learns that a turn wrote a file of that name, not where. The
exact fix keeps the path at projection; it belongs in the projector and is not in this change.
Second, a citation neighbour is not checked against the tree at HEAD, since the citation graph is
read at other cuts; its refs are repository-relative paths projected from the repository's
history, so they denote its files. Third, the client that spawns the server also reads its
standard error, where a refusal's traceback and whatever a library or a child process writes go
unfiltered.

\section{Future work}

The cleaner repair labels each edge at the store with the join of its endpoints' strata, so that
every reader, not only the universe builder, applies the rule; the noninterference statement could
then be proved over a model of the stores, as PLN-2 is for the vector plane. An event projector
that keeps a written file's path would let a doc's id never stand for a vault file. A dialogue
filtered of turns that quote notes would let a guest read conversations without trusting their
contents.

\section{Conclusion}

A second principal for an external agent is a small grant: two planes, read-only, over four
strata. Its refusals are a finite check and are proved. The adversarial battery found that the
check was not enough, because an admitted row named an excluded node, and a red team found that a
test against the vault's path was not enough either, because a path has many spellings. Showing
only what an allow list names and withholding every other reference whole makes the guest's
answers independent of the notes, within the limits of \cref{sec:limits}, and a two-store test
and a test of the spellings hold that in place.
